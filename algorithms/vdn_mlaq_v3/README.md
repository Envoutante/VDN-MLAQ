# VDN-MLAQ v3：局部观测个体 Q 表

## 来源与改动

从提交 `3aede09` 中的 v1 完整复制。v3 不继承 v2 的局部虚拟动作、个体计数或个体 UCB 选人；全局虚拟入口仍让所有智能体联合想象。MLAQ、v1、v2 的算法目录保持不变。

个体价值由 `Q_i(s, a_i)` 改为 `Q_i(o_i(s), a_i)`：

| 智能体 | 可见面板 |
|---|---|
| Alice | 1、2、3 |
| Bob | 3、4、5 |
| Chad | 5、6、7 |

观测按固定面板顺序记录每个面板上的物体或 `EMPTY`，不包含区域外物体的位置。面板 3、5 分别是相邻两人的重叠区域。局部观测只用于个体 Q 表索引；LLM 仍接收完整状态。

例如两个全局状态仅在黄块位于 panel6 还是 panel7 上不同，Alice 的局部观测相同，因此她的同一个体动作会读写同一 Q 条目；Chad 的观测不同，对应不同条目。状态缺失、格式非法、同面板出现多个物体时明确报错，不把解析失败当成空面板。

## 价值如何更新和使用

1. 在完整状态 s 下，从已发现的联合动作 a 中拆出各人的 a_i，再从 s 提取各人的 o_i。
2. 计算 `Q_tot(s,a) = Σ_i Q_i(o_i(s),a_i)`。全局 UCB 和真实动作选择继续使用这一和值。
3. 对图中每条有效联合转移计算团队 TD 误差。奖励、终止条件及下一状态仍使用全局状态；下一步 max 仅覆盖该全局节点已发现的有效联合动作。
4. 同一个 `(i,o_i,a_i)` 可能出现在不同全局状态的多条转移边中。将这些边本轮的 TD 误差取平均，再乘原学习率更新该条目。这里的 k 是边数，不是路线数、访问次数或独立样本数。
5. 保留 v1 的同步迭代、学习率、折扣、最大迭代次数和 TD 残差停止阈值。

搜索图不会因局部观测相同而合并全局节点。共享到动作的价值也不会把它自动加入另一全局节点的动作集合；LLM 仍负责发现候选，联合检查与下一状态预测流程不变。提示词、环境和对话流程均保持 v1 内容。

## 运行和输出

在项目根目录激活原 mlaq 环境后：

```bash
python algorithms/vdn_mlaq_v3/run_benchmark.py --llm deepseek-v4-flash --compare_q
```

单独运行：

```bash
python algorithms/vdn_mlaq_v3/run_MLAQ.py --task sort_dialog --optimal_steps 2 --skip_display --compare_q
```

只支持 `sort_dialog`；其他任务入口明确拒绝，不能把面板观测规则直接套到 Sandwich。无需 `--algo`。默认输出为项目根 `data/sort_dialog/vdn_mlaq_v3/<批次>/`；续跑用 `--epoch vdn_mlaq_v3/YYYYMMDD_HHMM`。密钥仍读项目根 `.env`，LLM 参数不训练。

公共 Q 对照工具通过 `get_q_i` 读取个体值，适配全局/局部两种索引。`Q_VDN` 列在 v3 批次中表示 v3 的实际估值，另一方仍是同图上的 MLAQ 副本估值，不是额外运行一次 MLAQ 在线实验。

`case_result.json` 新增 `q_key_schema`、`last_q_diagnostics`、`last_temp_q_diagnostics`。后两者只记录最后一次永久/临时图求解，包含迭代次数、最后一轮更新前最大 TD 残差、实际最大 Q 改变量、是否达到 TD 阈值、是否耗尽迭代次数及共享条目数量；不是整个 case 的统计汇总。未进行过求解时诊断为空。

## 保存、加载与研究边界

表的键为 `(局部观测元组, 个体动作)`，`q_key_schema='sort_local_panels_v1'`。保存包含 Q 表；正常 `LangTree(load=True)` 加载仍沿用 v1 的行为：复用图节点、重新建立空 Q 表，再基于当前目标估值。它不自动把旧的全局状态 Q 值平均成局部 Q，也不精确恢复中断时的 Q。直接 `torch.load` 只是反序列化，不能当作新旧键结构转换接口。

局部观测会合并远端状态不同的经验，可能增加共享，也可能造成价值冲突。保留原停止条件便于对照，但最大 TD 残差可能无法降到阈值，此时会用满迭代预算；Q 改变量小也不等于所有 TD 误差都小。v3 不保证更快、更优，个体 Q 也不自动成为真实贡献。

这是“完整状态规划 + 局部观测价值分解”，不是完整的部分可观测决策或分散执行方案。离线验证脚本、日志与报告保存在研究目录 `experiments/20261109_v3_local_observation`。真实 LLM 的路径质量、探索成本与多次重复结果仍需正式实验验证。
