## 第 1 步

入口参数：`--exploration_mode local_random --exploration_seed 7`。
原默认 joint 和 local_round_robin 对照保留。基准选择、提案内容、动作检查、三次重试、UCB 和失败处理不变。
种子由 `实验种子:run_id:case_id` 派生，每个 case 开始时初始化独立 Random。
因此跳过已完成 case 不会消耗后续 case 的随机序列；不保证不同记忆/LLM 返回下的完整轨迹一致，也不保存 case 中途 RNG 状态。
参数写入现有 args JSON；日志记录 case_seed 和每次选中的智能体；续跑提示保留种子。

验证：`python -m unittest discover -s tests -p test_local_random.py -v`。
测试从真实源码提取 predict_action，使用树和 LLM 替身执行控制流，不依赖机器人运行环境。
本轮未调用真实 LLM、未运行付费 benchmark，不能据此声称性能提升。
